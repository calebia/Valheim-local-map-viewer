# nooo — Valheim Offline Map

Viewer estático e offline do mundo Valheim com seed `nooo`, usando o mapa exportado do valheim-map.world e locations pré-calculadas.

## Recursos

- Mapa em tiles locais de alta resolução
- Zoom e pan
- Busca de locations
- Filtros por categoria
- Pins calibrados sobre o mapa
- Sem gerador procedural em runtime
- Sem iframe do valheim-map.world
- Sem loop contínuo de renderização quando o mapa está parado

## Rodar

No Windows, execute:

```text
ABRIR_MAPA.bat
```

Também é possível servir a pasta com qualquer servidor HTTP estático.

## Dados

- Seed: `nooo`
- World version: `0.221.10`
- Mapa base: exportado do valheim-map.world
- Locations: exportadas do mesmo mundo e processadas para uso offline
